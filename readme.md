# kollektivavtal.github.io

Homepage for the kollektivavtal archive subsite of the arbetsmarknad Swedish labour market documentation project.

## Commands

- Run `pnpm dev` to run the dev server at http://localhost:3000/.
- Run `pnpm build` to produce a build
- Run `pnpm build` to deploy the build to production
